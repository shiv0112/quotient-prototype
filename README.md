# Quotient prototype

Clickable UX prototype for **Quotient**, an AI copilot for Singapore financial advisers (NUS IS5116 Digital Entrepreneurship project).

Live: https://shiv0112.github.io/quotient-prototype/

All names, cases, insurers (Harbour Assurance, Meridian Life, Orchid Mutual) and numbers are made up for the demo. Use the **Demo** button (bottom right) to jump between screens, switch web/desktop edition and light/dark, and reset the demo.
